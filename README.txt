xyntheria – installera som app på iPhone

1. Ladda upp hela innehållet i den här mappen (index.html, manifest.webmanifest, service-worker.js och mappen icons) till ett GitHub-repository.
2. Aktivera GitHub Pages: Settings > Pages > Deploy from a branch > main > /(root) > Save.
3. Öppna den publicerade HTTPS-adressen i Safari på iPhone.
4. Tryck på Dela > Lägg till på hemskärmen > Lägg till.
5. Öppna xyntheria via ikonen på hemskärmen.

Viktigt: Att öppna en nedladdad HTML-fil direkt i Filer skapar inte en installerbar app.
Spelets framsteg sparas lokalt per webbadress och webbläsare; befintliga resultat flyttas inte automatiskt från en annan adress.
Butikens köp är bara simuleringar, inte riktiga köp. För publicering via App Store krävs ytterligare byggsteg, Apple Developer-konto och korrekt köpimplementation.
